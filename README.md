# KemArt Wears — Portfolio Website

A lightweight, responsive static website built with HTML, CSS and JavaScript. No npm install or build step required.

## Deploy to Vercel
1. Extract this ZIP into a folder.
2. Push the folder to a GitHub repository.
3. In Vercel, select Add New → Project and import the repository.
4. Framework Preset: Other. Build Command: leave blank. Output Directory: leave blank (root). Deploy.

Alternatively, use Vercel CLI: `npx vercel` from the extracted directory.

## Customize
- Update text and sections in `index.html`.
- Replace images in `images/`, preserving their filenames, or change image paths in `index.html`.
- Instagram links currently point to https://www.instagram.com/kemart_wears/
- Photos are supplied by the user; please confirm permission to publish images of children before deploying.
